## PROBLEM STATEMENT

A deserving student wishes to organize her study in order to maximize her cumulative score in the $n$ courses of the semester. For this purpose, she analyzes the syllabuses and comes up with an estimation $c_{ij}$ of the score she will get in course $i$ if she devotes to it $j$ hours out of the total $H$ study hours available. Her goal is now determining how many hours to devote to each course.

## 1. Solution
The solution will be an ordered sequence of the different $j$ hours out of the total $H$ hours that the student can devote to the studying each course $i$. Hence,

$S = \langle j_1, j_2, \dots, j_n \rangle$

Restrictions:

$j \in \mathbb{Z}^+ \cup \{0\} \mid 0 \le j \le H$

$\sum S \le H$

$t$ will be defined as the total grade

## 2. Objective function

What we want to do is obtain the maximum cumulative score for the n courses. Our function will be defined as:

$\max g(S) = \sum_{i=1}^n c_{i,{j_i}}; \ c_{i, j} \in \mathbb{R}^+$ (or grades $\in [0, 10]$).

## 3. Decisions

How much time shall I allocate to subject $i$? (Multi-way)

## 4. Optimal Substructure

Let's define our optimal solution as:

$S^* = \langle j_1^*, j_2^*, \dots, j_n^* \rangle$

$g(S^*) = \sum_{i=0}^n c_{i,{j_i}^*}$ will thus be optimal.

Hypothesis: $S' = S^*_{2\to n}$ will be optimal for the remaining courses starting from the second to n. Hence, this solution will be optimal for a new total grade being $t_{2\to n}=t-c_{i,{j_1^*}}$, for the remaining time $H_{2\to n}=H-j_1^*$

**Proof by Contradiction:**

If $S'$ is not the most optimal, then there must exist an $S''$ that is more optimal.

Let's assume then that $S'' = \langle j_2'', j_3'', \dots, j_n''\rangle$

Hence, $S'''$ will be defined as $S''' = S'' \cup \{j_1^*\}$

Its total time will be:

$g(S''') = j_1^*+g(S'') > j_1^*+g(S') = g(S^*)$

$\cancel{j_1^*}+g(S'') > \cancel{j_1^*}+g(S')$

$g(S'') > g(S')$ is not possible, because $S^*$ is the optimal set and $S'$ is made from that one, as it's $S^*_{2\to n}$. Hence, its optimal by contradiction.

## 5. Subproblems

$g_{i, j}$ shall be the maximum grade possible obtained from courses $0..n$ and maximum time H.

$j \in \mathbb{Z}^+ \cup \{0\} \mid 0 \le j \le H$

$i \in \mathbb{Z}^+ \mid 1 \le i \le n$

What we want to compute at the beginning of a problem is $g_{n, H}$

## 6. Bellman equation

$g_{i,j} = \begin{cases}
0 & i > n \\
\max\limits_{0\le k\le j}{c_{i,k}+g_{i+1, j-k}} & 1\le i \le n
\end{cases}$

## 8. Algorithm

```
for j <- 0 to h do
    c_{i+1, j} <- 0
end

for i <- n down to 1 do
    for j <- 0 to h do
        c_{i,j} <- -infin
        for k <- 0 to j do
            q <- C_{i,k}+c_{i+1, j-k}
            if q > c_{i,j} then
                c_{i,j} <- q
                D_{i,j} <- k
            end
        end
    end
end

S <- c_{1,h} 

```

In the D table you will find the amount of hours she will have to devote for each course in order to get the maximum score.

This will be useful for the reconstruction:

```
j <- h
for i <- 1 to n do
    E_i <- D_{i,j}
    j <- j - E_{i}
```

With this we will be able to obtain an array with the number of hours we have to dedicate to each subject

The computational complexity will be:
O(n*H) for the space complexity
O(n*H^2) for the time complexity
