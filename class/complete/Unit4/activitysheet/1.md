## PROBLEM STATEMENT

Given a fraction a/b, express it as the sum of a minimal number of different fractions with unit
numerator, e.g., 3/5 = 1/2 + 1/10.

## SOLUTION
The solution will be defined as a multiset of numbers

$S = <s_1, s_2, \dots, s_n>; \ S \in \mathbb{Z^+}\setminus\{0\}$

Given that $\sum_{i=0}^n \frac{1}{s_i} = \frac a b$

## OBJECTIVE FUNCTION
We want the minimum amount of fractions necessary to add up to the fraction a/b, hence our objective function shall be:

$min(f(S)) = |S|$

## DECISIONS
Going from $\frac{1}{1}$ to $\frac{1}{\infin}$, should I add this number? (Binary)

## OPTIMAL SUBSTRUCTURE
We will define our optimal solution as:

$S^* = <s_1^*, s_2^*, \dots, s_n^*>$

$f(S^*)=|S^*|$ will thus be optimal.

Hypothesis: The subset $S' = S_{2\to n} = S^*\setminus\{s_1^*\}$, will be optimal for obtaining $\frac{a}{b}-\frac{1}{v_1^*}$.

**Proof by contradiction:**

If $S'$ is not optimal, then there must exist an $S''$ that is more optimal.

Assume $S''=<s_2'', s_3'', \dots, s_n''>$

Hence, the optimal solution will be $S''' = S'' + \frac{1}{s_1''}$

For $S''$ to be true, then:

$f(S''') = f(S'') + \cancel1 < f(S') + \cancel1 = f(S^*)$

$f(S'') < f(S')$ is not possible because S^* is the optimal set, hence, we have proven that $S'_{2\to n}$ is optimal by contradiction.

## GREEDY INGREDIENTS

**Initialization:** $S \leftarrow \varnothing, \ l \leftarrow 1$

**Completion:** $\frac{a}{b}=\sum S$

**Generation:** $Candidates(S) = l + 1$

**Selection:** $Select(S,a,b)= \sum_{i=0}^n\frac{1}{s_i} \le \frac{a}{b}$

**Extension:** $S \leftarrow S \cup \{\text{selected number}\}

## ALGORITHM

    last <- last + 1
